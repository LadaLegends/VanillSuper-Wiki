# Дополнительно

### Музыка прямо в игре

Благодаря аддону для голосового чата можно воспроизводить и записывать любую музыку на пластинку.

* /disc burn \<url> \[название] - записать пластинку
* /disc erase - стереть музыку с пластинки
* /disc search <запрос> - поиск музыки
