# Локальная погода

{% hint style="info" %}
Функция доступна только с подпиской [Plus](../../a/plus.md).
{% endhint %}

### Как изменить погоду?

1. Введите команду /pweather.
2. Выберите нужную погоду.
3. **Готово**!
