# Item Lore

{% hint style="warning" %}
Функция Item Lore больше недоступна для Plus.[Plus](../../a/plus.md)
{% endhint %}

Установить название — `/rename (ваше название)`\
Установить описание — `/setlore (строка) (ваше описание)`

<div align="left" data-with-frame="true"><figure><img src="../../.gitbook/assets/image (18).png" alt=""><figcaption></figcaption></figure></div>

### Доступные цвета

{% hint style="info" %}
Можно использовать &ванильные цвета и HEX  (`#RRGGBB`).

Для использования HEX, необходимо поставить `&` перед цветом. Например: `&#RRGGBB`
{% endhint %}

| Код  | Название          | Цвет    |
| ---- | ----------------- | ------- |
| `&0` | Чёрный            | #000000 |
| `&1` | Тёмно-синий       | #0000AA |
| `&2` | Тёмно-зелёный     | #00AA00 |
| `&3` | Темно-бирюзовый   | #00AAAA |
| `&4` | Тёмно-красный     | #AA0000 |
| `&5` | Тёмно-фиолетовый  | #AA00AA |
| `&6` | Золотой           | #FFAA00 |
| `&7` | Серый             | #AAAAAA |
| `&8` | Тёмно-серый       | #555555 |
| `&9` | Синий             | #5555FF |
| `&a` | Зелёный           | #55FF55 |
| `&b` | Бирюзовый         | #55FFFF |
| `&c` | Красный           | #FF5555 |
| `&d` | Светло-фиолетовый | #FF55FF |
| `&e` | Жёлтый            | #FFFF55 |
| `&f` | Белый             | #FFFFFF |
