# Подсчет АР

{% hint style="warning" %}
Вы находитесь на скрытой странице. Информация на ней, скорее всего, неактуальна.&#x20;
{% endhint %}

{% hint style="info" %}
**АР** - Алмазная Руда
{% endhint %}

### Использование <a href="#usage" id="usage"></a>

| Команда                                                       | Назначение                                |
| ------------------------------------------------------------- | ----------------------------------------- |
| <mark style="color:green;">/money inv</mark>                  | Подсчет АР в инвентаре                    |
| <mark style="color:green;">/money block</mark>                | Подсчет АР в блоке на который вы смотрите |
| <mark style="color:green;">/money ec</mark>                   | Подсчет АР в эндер сундуке                |
| <mark style="color:green;">/money all</mark>                  | Подсчет АР в в инвентаре и эндер сундуке  |
| <mark style="color:green;">/money-send <игрок> <число></mark> | Перевод Алмазов игроку                    |

Подсчет учитывает оба вида АР, а так же считает в шалкерах которые находятся в блоке/инвентаре/ендер сундуке.
