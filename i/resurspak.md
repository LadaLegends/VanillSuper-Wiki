# Ресурспак

### Как скачать?

Есть два основных способа установки серверного ресурспака.

1. Автоматически через команду **/rp**.
2. Вручную через скачивание файла.

### Через команду

Все крайне просто.&#x20;

1. Введите комнду /rp.
2. В появившемся окне выберите "Да".
3. Дождитесь окончания загрузки ресурспака.
4. **Готово**!

### Через скачивание файла.

{% hint style="info" %}
После открытия четвертого сезона тут будет файл.
{% endhint %}
