# Памятка модератора

## Доступные команды

| Команда    | Объяснение                                                                                                                                                                                                                                | Пример                                                              | Мин. роль     |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------- | ------------- |
| /vanish    | Стать невидимым для других игроков.                                                                                                                                                                                                       | /vanish                                                             | Модератор     |
| /ban       | Команда блокирует аккаунт игрока на указанное время. _Использовать при строгой необходимости!_                                                                                                                                            | /ban <игрок> \[время] \[причина]                                    | Модератор     |
| /mute      | <p>Команда мутит игрока, из-за чего тот не сможет отправлять сообщения в чат. <br><em>Использовать при нарушениях раздела "5".</em> <br><strong>Хелперам надо использовать /tempmute</strong></p>                                         | /mute <игрок> \[время] \[причина]                                   | Хелпер        |
| /warn      | <p>Выдает виртуальное предупреждение игроку. По умолчанию оно пропадет через семь дней. Собрав три предупреждения, игрок получит бан на семь дней. <br>Основная мера наказания. <em>Использовать при любых не грубых нарушениях.</em></p> | /warn <игрок> \[причина]                                            | Модератор     |
| /kick      | <p>Команда кикает игрока с сервера. После этого игрок сможет зайти на сервер снова. Не блокировка!<br><em>Примеров использования нет.</em></p>                                                                                            | /kick <игрок> \[причина]                                            | Хелпер        |
| /unban     | <p>Снимает блокировку с аккаунта игрока. Работает только на тех, кому вы сами выдали наказание.<br><em>Необходимо уведомить администратора при использовании!</em></p>                                                                    | /unban <игрок>                                                      | Модератор     |
| /unmute    | <p>Снимает мут с аккаунта игрока. Разрешает использовать чат. Работает только на тех, кому вы сами выдали наказание.<br><em>Необходимо уведомить администратора при использовании!</em></p>                                               | /unmute <игрок>                                                     | Хелпер        |
| /unwarn    | Снимает **последнее** предупреждение с аккаунта игрока. Использовать при ошибочном выдаче варна. Работает только на тех, кому вы сами выдали наказание. _Необходимо уведомить администратора при использовании!_                          | /unwarn <игрок>                                                     | Модератор     |
| /history   | Показывает историю наказаний игрока.                                                                                                                                                                                                      | /history <игрок> \[наказаний]                                       | Модератор     |
| /checkban  | Проверяет, заблокирован ли аккаунт игрока.                                                                                                                                                                                                | /checkban <игрок>                                                   | Модератор     |
| /checkmute | Проверяет, заглушен ли аккаунт игрока.                                                                                                                                                                                                    | /checkmute <игрок>                                                  | Хелпер        |
| /checkwarn | Проверяет, есть ли предупреждения у игрока.                                                                                                                                                                                               | /checkwarn <игрок>                                                  | Хелпер        |
| /co near   | Показывает все действия совешенные вокруг вас в радиусе 10 блоков.                                                                                                                                                                        | /co near                                                            | Хелпер        |
| /co lookup | Посмотреть историю взаимодействий игрока по указанным параметрам (время, радиус, действие, игрок).                                                                                                                                        | /co lookup user: <игрок> time: 30d radius: #global action:container | Модератор     |
| /freeze    | "Замораживает" указанного игрока ограничивая его действия до тех по, пока вы его не разморозите.                                                                                                                                          | /freeze <игрок>                                                     | Модератор     |
| /unfreeze  | Размораживает игрока, который был заморожен командой /freeze.                                                                                                                                                                             | /unfreeze <игрок>                                                   | Модератор     |
| /spectate  | Наблюдать за указанным игроком в режиме спектатора.                                                                                                                                                                                       | /spectate <игрок>                                                   | Модератор     |
| /tp        | Телепортация к игроку или на точные координаты.                                                                                                                                                                                           | /tp <локация/игрок> \[2игрок]                                       | Ст. модератор |
